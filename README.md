# Spotket Digital

Marketing site for Spotket Digital, an AI automation and web design
agency for small businesses — AI chatbots, booking automation, review
generation, and custom websites.

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Configuration

- `NEXT_PUBLIC_SITE_URL` — canonical site URL used in metadata, sitemap,
  and robots (defaults to `https://www.spotket.com`).

## Deploying to Vercel

```bash
vercel          # preview deployment
vercel --prod   # production
```

Or push to GitHub — the project auto-deploys from `main`.
